# 電気工事士ランダムクイズの重複扱いメモ

対象: `denco-app/quiz.html` / `denco-app/questions.json`

最終更新: 2026-05-15

## 結論

改修前の「クイズを始める」は、問題データ1件ごとの `_qid` を履歴に保存して、次回以降の20問から除外していた。

改修後は `_qid` に加えて `duplicateGroup` も履歴に保存し、人間が同じ型と感じる問題群もランダム20問では避ける。

選択肢の順番だけで同一判定しているわけではない。現状の判定基準は、問題文・選択肢・正解ではなく、`questions.json` の各レコードに付く問題IDである。

## 現状の実装

- 1セットは `QUICK_QUIZ_QUESTION_COUNT = 20`
- 出題済み履歴は `localStorage` の `denkoQuickQuizIssuedQids` と `denkoQuickQuizIssuedGroups`
- クイッククイズ開始時に、今回選ばれた問題の `_qid` を履歴へ保存
- クイッククイズ開始時に、今回選ばれた問題の `duplicateGroup` も履歴へ保存
- 次回は `quickQuizIssuedIds` に含まれる `_qid` と `quickQuizIssuedGroups` に含まれるグループを除外
- 残り問題が20問未満になると履歴を自動リセット

このため、同じ `_qid` と同じ `duplicateGroup` は、原則として使い切りまで再出題されない。

## 人間には同じに見えやすい例

完全一致の問題文重複は確認時点で0件。ただし、以下のような「同じ型」の候補がある。

### 数値だけ違う計算問題

- id 1: 抵抗4Ωと6Ωを並列接続したときの合成抵抗
- id 151: 抵抗8Ωと12Ωの並列回路で、8Ωの枝電流を求める問題

改修で id 151 は、合成抵抗の数値違いではなく「並列回路では各枝に同じ電圧がかかる」という別角度の問題に変更した。

### 同じ記号・同じ知識を問う問題

- id 181, 182, 185: 3路・4路スイッチと3か所点滅
- id 183, 184, 187: WP・T・E/ET/EET などコンセント傍記

選択肢や表現が違っても、問われている知識はかなり近い。

### 同じ施工基準を問う問題

- id 23, 137, 159, 163: 支持点間の距離
- id 135, 162: 地中電線路の埋設深さ
- id 25, 191: D種接地工事の接地抵抗値

厳密には条件が違う場合があるが、短時間に続くと「また同じ系統」と感じやすい。

改修で id 159 は、支持点間距離の再確認ではなく、ステップル固定時の外装損傷防止を問う実務判断問題に変更した。

## 品質優先の改良方針

このアプリの価値は問題の質で決まる。ここは単なる重複排除ではなく、良問をそろえるためにコストをかける。

目的は、次の3つ。

- 受験者が「また同じ問題だ」と感じる体験を減らす
- 同じ論点でも、出すなら別角度・別条件・別ミス誘導として意味を持たせる
- ランダム20問で、計算・施工・器具・法令・配線図が偏らず、毎回きちんと練習になる状態にする

AI類似判定や外部APIに依存する必要はない。ただし、問題データには人間が管理する品質メタデータを追加する。

例:

```json
{
  "id": 1,
  "duplicateGroup": "theory_parallel_resistance",
  "learningPoint": "並列抵抗の合成抵抗",
  "qualityStatus": "keep",
  "category": "電気理論",
  "question": "抵抗4Ωと6Ωを並列接続したときの合成抵抗として、正しいものはどれか。"
}
```

### 追加するメタデータ

- `duplicateGroup`: 人間が同じ型と感じる問題群
- `learningPoint`: この問題で学ばせたい1つの論点
- `qualityStatus`: `keep` / `revise` / `merge` / `replace`
- `variantRole`: 同じ論点内での役割。例: `basic`, `calculation`, `exception`, `trap`, `field_practice`

同じ `duplicateGroup` の問題を複数残す場合は、`variantRole` が違うことを条件にする。役割が同じなら、片方は統合または差し替え候補にする。

## ランダム20問での扱い

ランダム20問では、履歴に `_qid` だけでなく `duplicateGroup` も保存する。

判定:

- `duplicateGroup` がある問題は、同じグループを出題済みなら除外
- `duplicateGroup` がない問題は、従来どおり `_qid` で除外
- どうしても20問に足りない場合だけ、グループ除外を緩める

ただし、通常学習や間違った問題の再出題では、反復学習の価値があるため、従来どおり問題単位で扱う。

## 年度別演習・疑似問題の扱い

年度別演習と疑似問題集は、本番形式の体感に近づけるため、50問を次の配分で構成する。

- 一般問題: 30問
- 配線図・記号・識別: 20問

年度別演習は「年度ベース」として扱う。選択した年度の問題だけで配線図・記号・識別20問を満たせない場合は、問題バンクから補完して50問配分を優先する。

注意:

- 公式試験そのものの完全再現ではない
- 年度名は、主にその年度の問題を中心にした演習セットを意味する
- 表示上も「年度ベース」「不足分は問題バンクから補完」と明記する

疑似問題集は、一般30問 + 配線図・記号・識別20問を維持しつつ、セットごとに easy / medium / hard の比率を変える。

## 図面問題の扱い

近年の公式過去問から200問を構成する場合、問31〜50の配線図問題を捨てない。

方針:

- 公式PDFの図面・写真ページをそのまま画像化してアプリに取り込まない
- 回路構成、接続関係、器具の配置などの「事実」を読み取り、アプリ側で自作図面として再構成する
- 公式図面の線幅、配置、記号の具体的な並び、写真、紙面レイアウトをトレースしない
- 自作図面は SVG または Canvas で作り、`image` には自作アセットのみを紐付ける
- 再構成が難しい問題は、アプリ内に取り込まず、公式PDFへの参照問題として扱う

禁止:

- 公式PDFページのスクリーンショットをそのまま使う
- 公式図面をなぞって、見た目が実質的に同じ図面を作る
- 公式写真を切り抜く、圧縮する、色調整して使う
- 問題文と一体化した公式紙面レイアウトを画像として表示する

許容する方向:

- 同じ電気的接続関係を、独自の配置・線幅・注記・凡例で描き直す
- 試験センターの図面ではなく、学習目的に合わせた簡略図を作る
- 「公式PDFの該当年度・問番号を参照」と案内し、画像自体は取り込まない

### 独自の抽象化

実物写真や公式図面を使わず、SVGアイコン・模式図・簡略回路図へ置き換える。

実装ルール:

- 器具写真は使わず、自作アイコンまたは模式図で表す
- 自作SVGには `desc` で「公式図面のトレースではない」旨を残す
- 公式紙面の配置、余白、矢印、番号配置を再現しない
- 必要な学習事実だけを抜き出し、学習しやすい構成に再設計する

現在の自作SVG例:

- `branch-circuit-example.svg`: 片切スイッチと非接地側電線
- `three-way-switch-control.svg`: 3路スイッチによる2か所点滅
- `four-way-switch-control.svg`: 4路スイッチを含む3か所点滅
- `outlet-suffix-symbols.svg`: E / ET / EET / WP / T の傍記整理
- `wire-count-slashes.svg`: 単線図の電線本数表示
- `vvf-cable-notation.svg`: VVF 2.0-3C の表記整理
- `outlet-box-icon.svg`: アウトレットボックスの特徴アイコン

写真問題の扱い:

- 公式写真は使わない
- 実物の特徴を覚えた方がよい問題は、自作SVGアイコンで識別ポイントだけを示す
- まずは頻出器具から、アウトレットボックス、リングスリーブ、差込形コネクタ、引掛シーリング、埋込連用取付枠などを候補にする
- 写真を使わなくても成立する場合は、特徴記述だけで出題する

問題データ例:

```json
{
  "source": "令和7年度上期 第二種電気工事士 学科試験",
  "sourceQuestion": 31,
  "image": "images/diagrams/self-made/branch-circuit-example.svg",
  "figureCaption": "自作図面：分岐回路の例",
  "isModified": true
}
```

## 問題文の構造化

公式問題文をそのままコピーせず、問題の「事実」と「表示文」を分けて管理する。

データ設計:

- `sourceFacts`: 回路構成、数値、単位、問う値などの事実
- `questionTemplate`: アプリ側で表示する独自テンプレート
- `params`: テンプレートへ差し込む数値・単位
- `expressionPolicy`: 表現上の扱い。例: `question_text_generated_from_template`

例:

```json
{
  "sourceFacts": {
    "circuit": "two_resistors_parallel",
    "values": { "r1_ohm": 4, "r2_ohm": 6 },
    "askedValue": "equivalent_resistance"
  },
  "questionTemplate": "抵抗 {r1}{unit} と {r2}{unit} を並列に接続した。合成抵抗として最も近い値を選べ。",
  "params": { "r1": 4, "r2": 6, "unit": "Ω" },
  "expressionPolicy": "question_text_generated_from_template"
}
```

アプリ側は `questionTemplate` と `params` がある場合、そこから問題文を生成する。これにより、問題文の著作権リスクを下げつつ、数値変更や出題バリエーション生成にも対応できる。

## 出典・改変表示

公式過去問を利用する場合は、アプリ上に出典と改変の有無を明記する。

表示方針:

- アプリの使い方欄と分野別メニューに、出典表示を常時掲載する
- 各問題データには `source`, `sourceUrl`, `sourceQuestion`, `isModified` を持たせる
- 問題文・選択肢・解説を編集した場合は `isModified: true` とする
- 図面を自作した場合は、公式画像ではなく自作図面であることを明記する

基本表示:

```text
出典：一般財団法人 電気技術者試験センター公表「第二種電気工事士試験の問題と解答」。
本アプリでは学習しやすいように一部の問題文・選択肢・解説を編集しています。図面・写真が必要な問題では、公式画像を取り込まず、自作図面または公式PDFへの参照で対応します。
```

仕上げ表示:

```text
本アプリの問題および図面は、第二種電気工事士試験の公表過去問題に基づき、事実関係を維持したまま独自に再構築・作図した学習用コンテンツです。
```

## 販売・商用利用の注意

公式サイトでは、教育目的など、電気主任技術者試験制度・電気工事士試験制度の意義に反しない限り、公表過去問題を問題集やテキストに使用する際の許諾および使用料は不要とされている。一方で、著作権は放棄されておらず、出典明記と改変明記が求められている。

そのため、広告付き無料公開や学習支援サイトとしての利用は進めやすいが、アプリ単体を有料販売する場合は慎重に扱う。

販売前に確認すべきこと:

- 有料販売が「教育目的など制度の意義に反しない使用」に含まれるか
- 公式過去問の図面・写真ページをそのまま商品価値の中心として販売してよいか
- アプリストアの審査で、公式試験センターとの関係を誤認させない表記になっているか
- 出典・改変表示が購入前画面、アプリ内、問題画面で十分に確認できるか

実務上の推奨:

- 公式過去問画像・原文を主商品として売る形は避ける
- 解説、進捗管理、弱点復習、重複排除、模擬演習など、独自の学習機能を価値の中心にする
- 有料販売する前に、電気技術者試験センターへ問い合わせ、商用アプリでの利用可否を確認する

販売を視野に入れる場合の結論:

- 公式図面・写真のデッドコピーは使わない
- 公式問題の単なる転載集として売らない
- 自作解説、自作図面、学習履歴、弱点分析、出題最適化を主価値にする
- それでも公式過去問由来である以上、販売前に権利元へ確認する

## 良問の基準

電気工事士アプリでは、次を満たすものを良問とする。

- 本試験で問われやすい論点に直結している
- 正解だけでなく、不正解選択肢にも意味がある
- 解説で「なぜ正しいか」「なぜ他が違うか」が分かる
- 暗記問題は、数字や語句を丸暗記させるだけでなく、条件との対応が見える
- 計算問題は、公式を使うだけでなく、単位・条件・典型ミスを意識できる
- 配線図・器具・施工は、現場イメージまたは試験図面での見え方につながる

反対に、次は弱い問題として修正対象にする。

- 数値だけ変えた同型問題で、学習上の差がない
- 正解選択肢だけが明らかに浮いている
- 問い方が曖昧で、条件不足に見える
- 解説が正解の言い換えだけになっている
- 本試験の出題感から遠い雑学寄りの問題

## 最初に精査する候補

まずは効果が見えやすいものから、人間の目で精査する。

- `theory_parallel_resistance`: id 1, 151
- `symbol_three_way_switch`: id 181, 182
- `symbol_weatherproof_outlet`: id 183, 184
- `wiring_support_interval`: id 23, 137, 159, 163
- `underground_burial_depth`: id 135, 162
- `grounding_d_resistance`: id 25, 191

この範囲は単に片方を消すのではなく、次のどれかに分類する。

- `keep`: どちらも良問。別角度として残す
- `revise`: 片方を実務・図面・例外条件などに寄せて差別化する
- `merge`: 片方に統合して、空いた枠は別論点の良問に差し替える
- `replace`: 同型反復の価値が薄いので、別の頻出論点へ差し替える

## 問題セット全体の目標

現状は205問。

- 電気理論: 26問
- 屋内配線・施工: 39問
- 機器・試験・計測: 49問
- 接地・漏電保護: 10問
- 配線図・記号・識別: 46問
- 法令: 35問
- 画像付き問題: 7問（すべて自作SVG）

まずは既存問題の質を上げる。数を増やす場合も、重複ではなく図面読解・記号識別・施工判断の幅を広げる。

短期目標:

- 体感重複グループを洗い出す
- 各グループに `learningPoint` と `variantRole` を付ける
- `qualityStatus: revise/merge/replace` の問題を決める
- ランダム20問で同じグループが連続・近接しにくいようにする

中期目標:

- 接地・漏電保護が10問と少ないため、良問を追加する
- 配線図・記号・識別は、暗記だけでなく図面読解寄りの問題を増やす
- 機器・試験・計測は49問あるため、似た暗記問題を整理し、測定器・工具・施工判断のバランスを見る
- 法令は数字暗記だけでなく、許可・資格範囲・工事可否の判断問題を増やす

## 実装順

1. `questions.json` に品質メタデータを追加する（実装済み）
2. 既存問題をグループ化し、明らかな同型問題から `duplicateGroup` を付ける（実装済み）
3. `startQuickQuiz()` の除外ロジックを `_qid` + `duplicateGroup` に拡張する（実装済み）
4. `pickBalancedQuickQuizDeck()` でカテゴリバランスに加えてグループ近接も避ける（実装済み）
5. 年度別演習・疑似問題集を本番形式50問（一般30問＋配線図・記号・識別20問）に近づける（実装済み）
6. 図面・記号・識別カテゴリに自作SVG問題を追加する（継続）
7. `qualityStatus` が `replace` の問題を、未カバー論点の良問へ差し替える（継続）

## 注意点

同じ型をすべて排除しすぎると、試験対策として必要な反復まで消える。

そのため、消すのではなく「役割を持たせる」ことを優先する。役割がない同型問題だけ統合・差し替えする。
