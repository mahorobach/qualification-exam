### Ⅲ-1 （図あり：3本棒並列と剛体板の応力分担）
直径D，長さlの3本の丸棒（棒1,2,3）が左端を壁，右端を剛体板で接合。棒1と棒3は弾性係数E₁，棒2はE₂（中心軸対称）。荷重Pを加えるときの棒1の応力σ₁と棒2の応力σ₂を求める。

断面積 A = πD²/4。変位適合条件：ε₁ = ε₂（剛体板なので全棒で変位が等しい）。
力の釣り合い：2×A×σ₁ + A×σ₂ = P。
変位適合：σ₁/E₁ = σ₂/E₂ → σ₁/σ₂ = E₁/E₂。

σ₁ = 4E₁P / [πD²(E₁+2E₂)]
σ₂ = 4E₂P / [πD²(E₁+2E₂)]

**正答：③**

θ = δ×n/[(n+1)(n+2)] = 30×7/(8×9) = 210/72 = 2.917 mm
H = δ*/θ = 3.75/2.917 = 1.286 ≈ 1.29

**正答：② 1.29**
